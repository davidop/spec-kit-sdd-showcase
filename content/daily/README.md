# Entrada editorial diaria

Añadir archivos `YYYY-MM-DD.json` que cumplan `content/schema/daily-video.schema.json`.

El contenido debe proceder del Resumen Tech Diario o de una selección expresamente autorizada. No atribuir a la conversación acceso automático desde GitHub Actions.

El ejemplo `content/examples/daily-video.example.json` es ilustrativo, no una noticia verificada ni un guion publicable.
