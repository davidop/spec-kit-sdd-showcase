# Spec Kit 1.4.1: notas para el guion

**Fecha de la versión:** 16 de noviembre de 2026.

Fuente primaria a contrastar antes de publicación:
- https://github.com/github/spec-kit/releases/tag/v1.4.1
- https://github.com/github/spec-kit/compare/v1.4.0...v1.4.1

Las notas de versión consultadas enumeran:
- Incorporación de **Multi-Repo Workspace Orchestration** al **catálogo comunitario** (#5436).
- Incorporación de una extensión de ciclo de vida para **Jira** al catálogo comunitario (#5438).
- Extensión **OKR Bets** y preset **OKR Bet Spec Section** en el catálogo comunitario (#5412, #5439).
- Correcciones de PowerShell para rutas con corchetes y tratamiento literal de rutas (#5396, #5399, #5404).
- Ajustes de workflows, integraciones y extensiones.

**Distinción fundamental:** la inclusión en el catálogo comunitario NO significa que Spec Kit 1.4.1 implemente orquestación multi-repositorio nativa ni que tres asistentes de IA colaboren automáticamente.

## Traducción al caso de uso
- El cotizador requiere cambios coherentes en API, web y, solo cuando corresponda, infraestructura.
- Mostrar el catálogo comunitario como una opción de ampliación del flujo, no como una ejecución demostrada.
- Las correcciones de PowerShell se pueden mencionar en una breve anotación visual, pero no forzar su aparición como parte de la lógica de la póliza.
- No presentar Jira/OKR como componentes obligatorios del cotizador.
